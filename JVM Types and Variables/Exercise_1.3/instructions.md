# Exercise 1.2 — Grade Calculator

Create GradeCalculator.java with these methods:

```java
    public static char letterGrade(int score)           // returns 'A', 'B', 'C', 'D', 'F'
    public static double average(int[] scores)          // returns the mean
    public static int highest(int[] scores)             // returns max value
    public static int lowest(int[] scores)              // returns min value
    public static boolean isPassingGrade(char letter)   // true if A, B, or C
```

1. In main, create an array of 6 test scores.
2. Print each score, its letter grade, and whether it's passing.
3. Print the class average, highest, and lowest.
