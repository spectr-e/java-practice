# Exercise 4.1 — BankAccount

Implement the full BankAccount class.

Then write a `BankAccountTest.java` (not a JUnit test yet — just a `main` method) that:

1. Creates two accounts
2. Makes several deposits and withdrawals
3. Attempts an invalid withdrawal (negative amount) and catches the exception
4. Attempts to overdraw and catches the exception
5. Prints both accounts using toString
6. Transfers money from one account to another (write a transfer method)
